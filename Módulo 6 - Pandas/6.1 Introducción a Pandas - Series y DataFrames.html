¿Por Qué Pandas?

Hasta ahora usamos listas y diccionarios. Eso funciona, pero se vuelve incómodo apenas los datos se parecen a una tabla: filas y columnas, como una hoja de Excel. Pandas es la librería de Python para trabajar con datos en forma de tabla.

Las Dos Librerías

Estas dos líneas van a estar presentes en prácticamente todo lo que hagamos de aquí en adelante. pd y np son los alias estándar de toda la comunidad de Python.

import pandas as pd
import numpy as np

Numpy en Una Diapositiva

Series = Array + Índice

Pandas está construido encima de Numpy. Un array es como una lista, salvo que todos sus elementos son del mismo tipo y las operaciones se aplican a todo el arreglo a la vez.

notas_lista = [8.5, 7.2, 9.1, 6.8]
notas_array = np.array(notas_lista)

print(notas_array + 1)   # Sumar 1 a cada elemento, de una sola vez
# [ 9.5  8.2 10.1  7.8]

Una Series de Pandas es, en el fondo, un array de Numpy con una etiqueta para cada elemento.

Series

Desde una Lista

Una Series es una columna de datos con un índice asociado. Por defecto, ese índice es numérico (0, 1, 2...).

notas = pd.Series([8.5, 7.2, 9.1, 6.8])
print(notas)
# 0    8.5
# 1    7.2
# 2    9.1
# 3    6.8

Series

Desde un Diccionario

Si la creas desde un diccionario, las claves se convierten en el índice automáticamente.

notas = pd.Series({'Ana': 8.5, 'Luis': 7.2, 'Marcela': 9.1})
print(notas)
# Ana        8.5
# Luis       7.2
# Marcela    9.1

Series

Índices No Numéricos

También puedes crear una Series desde un array y asignarle un índice explícito. El índice no tiene que ser numérico: puede ser texto, fechas, o cualquier etiqueta con sentido.

notas_array = np.array([8.5, 7.2, 9.1])
notas = pd.Series(notas_array, index=['Ana', 'Luis', 'Marcela'])
print(notas)
# Ana        8.5
# Luis       7.2
# Marcela    9.1

DataFrame

Nuestro Dataset de Referencia

Un DataFrame es una tabla: varias columnas que comparten el mismo índice de filas. Se crea desde un diccionario de listas, donde cada clave es una columna. Este es nuestro dataset de referencia para el resto del módulo.

datos = {
    'nombre':     ['Ana', 'Luis', 'Marcela', 'Pedro', 'Sofía'],
    'carrera':    ['Ingeniería', 'Administración', 'Medicina', 'Ingeniería', 'Derecho'],
    'semestre':   [3, 5, 2, 3, 6],
    'nota':       [8.5, 7.2, 9.1, 6.8, 8.0],
    'asistencia': [95, 80, 98, 70, 88]
}
estudiantes = pd.DataFrame(datos)

DataFrame

Desde una Lista de Diccionarios

Cada diccionario de la lista representa una fila.

filas = [
    {'nombre': 'Ana', 'carrera': 'Ingeniería', 'nota': 8.5},
    {'nombre': 'Luis', 'carrera': 'Administración', 'nota': 7.2},
]
df = pd.DataFrame(filas)

DataFrame

Desde un Array de Numpy

Indicando el nombre de las columnas con columns.

matriz = np.array([[8.5, 95], [7.2, 80], [9.1, 98]])
df2 = pd.DataFrame(matriz, columns=['nota', 'asistencia'])

Selección

Seleccionar Columnas

Una sola columna con df['columna'] (devuelve una Series). Varias columnas con una lista de nombres df[['col1', 'col2']] (devuelve un DataFrame).

print(estudiantes['nombre'])          # Series
print(estudiantes[['nombre', 'nota']]) # DataFrame

Indexación

.loc vs .iloc

Esta es una de las partes que más confunde al principio. .loc selecciona por etiqueta (el valor del índice). .iloc selecciona por posición (como en una lista, desde 0).

Regla práctica: si accedes por nombre/etiqueta, usa .loc. Si accedes por posición/orden, usa .iloc.

Indexación

La Diferencia en la Práctica

Con el índice numérico por defecto, ambos parecen iguales. La diferencia se nota cuando cambiamos el índice a algo no numérico:

por_nombre = estudiantes.set_index('nombre')

por_nombre.loc['Marcela']    # Busca por el nombre (etiqueta)
por_nombre.iloc[2]           # Busca por posición: la fila en índice 2

# Filas 0 a 2 (incluyente), solo 2 columnas
estudiantes.loc[0:2, ['nombre', 'nota']]

# Primeras 3 filas, primeras 2 columnas, por posición
estudiantes.iloc[0:3, 0:2]

Transformar

Agregar Nuevas Columnas

Se agrega asignando un valor a un nombre de columna nuevo — incluso calculándola a partir de otras columnas existentes.

estudiantes['aprobado'] = estudiantes['nota'] >= 7.0
print(estudiantes[['nombre', 'nota', 'aprobado']])
#     nombre  nota  aprobado
# 0      Ana   8.5      True
# 3    Pedro   6.8     False

Numpy en Pandas

Redondeo y Conversión de Tipos

.round(n) redondea a n decimales. .astype(tipo) convierte a otro tipo de dato. Ambos vienen de Numpy, pero se usan sobre columnas de Pandas.

estudiantes['nota'] = estudiantes['nota'].round(0)
estudiantes['semestre'] = estudiantes['semestre'].astype(float)

print(estudiantes.dtypes)
# nombre     object
# semestre  float64
# nota      float64
