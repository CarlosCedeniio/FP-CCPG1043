Carga de Archivos y Limpieza de Datos

Unidad 06 · Clase 2

Cargar un CSV, tratar nulos y duplicados, y dejar los datos listos para analizar.

Antes de Analizar

La Realidad de los Datos

La clase pasada creamos DataFrames a mano, con datos perfectos. En la vida real, los datos casi nunca llegan limpios: encuestas, exportaciones de Excel, sistemas distintos... traen valores en blanco, filas repetidas, mayúsculas inconsistentes.

Vamos a trabajar con una versión cruda (sin limpiar) de nuestro dataset de estudiantes: estudiantes_crudo.csv.

Cargar Datos

pd.read_csv()

Así se ve estudiantes_crudo.csv en un editor de texto. Usa ; en vez de , (muy común en exportaciones de Excel en español) y a Pedro le falta la nota:

nombre;carrera;semestre;nota;asistencia
Ana;Ingeniería;3;8.5;95
Luis;administración ;5;7.2;80
Pedro;INGENIERÍA;3;;70
...

Cargar Datos

Tres Argumentos Clave

import pandas as pd

df = pd.read_csv('estudiantes_crudo.csv', sep=';')

sep

Carácter separador de columnas (',' por defecto)

header

Fila con los nombres de columna (0 por defecto; None si no hay encabezado)

Cargar Datos

index_col

Define qué columna usar como índice de filas, en vez del índice numérico por defecto.

df2 = pd.read_csv('estudiantes_crudo.csv', sep=';', index_col='nombre')
print(df2.head(2))
#                    carrera  semestre  nota
# nombre
# Ana             Ingeniería         3   8.5
# Luis       administración          5   7.2

Ojo: si la columna usada como índice tiene valores repetidos (como nombre, porque Ana aparece dos veces), el índice queda repetido — señal de que hay algo que limpiar.

Guardar Datos

pd.to_csv()

Una vez que limpiemos el dataset, lo normal es guardar el resultado en un archivo nuevo, para no perder el trabajo ni tocar el original.

df.to_csv('estudiantes_intermedio.csv', index=False)

index=False evita que la columna de índice numérico se guarde como una columna más — casi siempre es lo que quieres.

Diagnóstico

Primero: .info()

Antes de limpiar nada, hay que saber qué tan sucio está el dataset. .info() muestra cuántos valores no nulos tiene cada columna — si un número es menor al total de filas, esa columna tiene nulos.

df.info()
# RangeIndex: 11 entries, 0 to 10
#  #   Column      Non-Null Count  Dtype
# ---  ------      --------------  -----
#  0   nombre      11 non-null     object
#  3   nota        10 non-null     float64  ← 1 nulo
#  4   asistencia  11 non-null     int64

Detectar

isna() y notna()

Pandas representa los valores faltantes como NaN. isna() devuelve True donde el valor es nulo; notna(), lo opuesto.

print(df['nota'].isna())
# 0     False
# 3      True   ← Pedro
# 4     False

Explorar

Contar Nulos por Columna

Combinando isna() con .sum() (True cuenta como 1) obtienes, de un vistazo, cuántos nulos tiene cada columna — el resumen que normalmente se revisa primero.

print(df.isna().sum())
# nombre        0
# carrera       0
# nota          1
# asistencia    0

Explorar

Ver las Filas con Nulos

Ya sabemos cuántos nulos hay; ahora veamos cuáles filas son, usando isna() como filtro booleano — antes de decidir qué hacer con ellas.

print(df[df['nota'].isna()])
#   nombre     carrera  semestre  nota  asistencia
# 3  Pedro  INGENIERÍA         3   NaN          70

Tratar

Rellenar con un Valor Fijo

La opción más simple de .fillna(): reemplazar todo nulo por un valor constante. Tiene sentido cuando la ausencia del dato ya significa algo — por ejemplo, un comentario vacío.

encuesta = pd.DataFrame({'nombre': ['Ana','Luis','Sofía'],
                          'comentario': ['Buena clase', None, 'Muy útil']})

print(encuesta['comentario'].fillna('Sin comentario'))
# 0       Buena clase
# 1    Sin comentario
# 2          Muy útil

Tratar

.mean() vs .median()

Para columnas numéricas, rellenar con el promedio es común, pero el promedio es sensible a valores atípicos. La mediana (el valor de en medio) es más robusta cuando hay notas muy altas o muy bajas.

df['nota'].fillna(df['nota'].mean())     # 8.14 — sensible a extremos
df['nota'].fillna(df['nota'].median())   # 8.25 — más robusta ante outliers

Tratar

.ffill() y .bfill()

Cuando los datos están en orden (por ejemplo, semana a semana), tiene sentido rellenar con el valor anterior (ffill, "forward fill") o el siguiente (bfill, "backward fill") en vez de un promedio.

asistencia_semanal = pd.Series([100, None, 90, None, None, 98])

asistencia_semanal.ffill()   # [100, 100, 90, 90, 90, 98]  ← copia el anterior
asistencia_semanal.bfill()   # [100,  90, 90, 98, 98, 98]  ← copia el siguiente

Tratar

Rellenar Distinto por Columna

Si distintas columnas necesitan distinta estrategia, .fillna() acepta un diccionario: una regla por columna, en una sola línea.

df.fillna({'nota': df['nota'].mean(), 'asistencia': 0})

Resumen: valor fijo → la ausencia ya es informativa · media/mediana → medidas numéricas continuas · ffill/bfill → datos secuenciales · diccionario → cuando cada columna necesita su propia regla.

Tratar

Eliminar Filas con .dropna()

Por defecto, .dropna() elimina toda fila que tenga al menos un valor nulo en cualquier columna.

df_sin_nulos = df.dropna()   # Elimina la fila de Pedro (índice 3)
print(len(df), len(df_sin_nulos))   # 11 10

¿Rellenar o eliminar? Si son pocos nulos y perder esa fila no te preocupa, elimínala. Si necesitas conservar todas las filas, rellena con un criterio razonable.

Tratar

how='any' vs how='all'

El parámetro how controla qué tan estricto es .dropna(). Con un ejemplo pequeño se ve claro:

ejemplo = pd.DataFrame({'a': [1, None, None], 'b': [2, 3, None]})

ejemplo.dropna(how='any')   # Elimina si falta AL MENOS un valor → quedan 1 fila
ejemplo.dropna(how='all')   # Elimina solo si TODOS son nulos     → quedan 2 filas

how='any' es el valor por defecto — el más estricto.

Tratar

subset: Solo Ciertas Columnas

Sin subset, .dropna() revisa todas las columnas. Con subset, solo elimina la fila si el nulo está en las columnas que indiques — ignora nulos en las demás.

df.dropna(subset=['nota'])   # Solo mira 'nota', ignora nulos en otras columnas
# Da igual en este dataset (solo 'nota' tiene nulos), pero es clave
# cuando hay varias columnas con datos faltantes

Tratar

axis=1: Eliminar Columnas

.dropna() no solo elimina filas: con axis=1 elimina columnas enteras que tengan algún nulo — útil cuando una columna completa no es confiable.

print(df.dropna(axis=1).columns.tolist())
# ['nombre', 'carrera', 'semestre', 'asistencia']
# 'nota' desapareció por completo: tenía un nulo

Explorar

Detectar Filas Duplicadas

.duplicated() devuelve una Series booleana: True en cada fila que es copia de una anterior. Con .sum() cuentas cuántas hay.

print(df.duplicated())
# 0     False
# 10     True   ← copia exacta de la fila 0

print(df.duplicated().sum())   # 1

Explorar

Ver las Filas Duplicadas

Igual que con los nulos, usa el resultado de .duplicated() como filtro para ver la fila repetida antes de eliminarla — nunca está de más confirmar qué se va a borrar.

print(df[df.duplicated()])
#    nombre     carrera  semestre  nota  asistencia
# 10    Ana  Ingeniería         3   8.5          95

keep='first' es el valor por defecto: marca como duplicada la segunda copia en adelante. Con df.duplicated(keep=False) se marcan todas las copias, incluida la primera.

Tratar

Eliminar con .drop_duplicates()

df_sin_duplicados = df.drop_duplicates()
print(len(df), len(df_sin_duplicados))   # 11 10

Por defecto compara todas las columnas: dos filas solo se consideran duplicadas si son idénticas en cada una.

Tratar

subset: ¿Qué Cuenta como "Igual"?

¿Qué pasa si dos filas comparten nombre y carrera, pero tienen distinta nota? Sin subset, no se consideran duplicadas — no son idénticas en todo.

ejemplo = pd.DataFrame({
    'nombre': ['Ana', 'Ana'], 'carrera': ['Ingeniería', 'Ingeniería'], 'nota': [8.5, 9.0]
})
ejemplo.duplicated()                              # [False, False] → no son idénticas
ejemplo.duplicated(subset=['nombre', 'carrera'])  # [False, True]  → mismo nombre+carrera

Tratar

¿Y las Columnas Duplicadas?

duplicated()/drop_duplicates() comparan filas. Para saber si dos columnas son idénticas (por ejemplo, tras combinar datos de dos fuentes), se usa .equals().

df['calificacion'] = df['nota']       # Columna duplicada por error

print(df['nota'].equals(df['calificacion']))   # True
df = df.drop(columns=['calificacion'])          # Se elimina como cualquier columna

Limpieza

Renombrar y Eliminar Columnas

df = df.rename(columns={'nota': 'calificacion'})
df = df.drop(columns=['asistencia'])

print(df.columns.tolist())
# ['nombre', 'carrera', 'semestre', 'calificacion']

rename() recibe {nombre_actual: nombre_nuevo}. drop(columns=[...]) también elimina filas si le pasas index=[...].

Limpieza

Limpiar Texto con .str

Fíjate en carrera: 'Ingeniería', 'administración ', 'INGENIERÍA', ' medicina'... ¡todo eso debería ser una sola categoría! El accesor .str aplica métodos de texto a toda una columna a la vez.

carrera_limpia = df['carrera'].str.strip().str.lower()
print(carrera_limpia)
# 0         ingeniería
# 1     administración
# 2           medicina

Limpieza

.str.contains()

.str.strip()

Quita espacios al inicio/final

.str.lower()

Convierte a minúsculas (también .str.upper())

print(carrera_limpia.str.contains('medicina'))
# True solo en Marcela y Valentina

Práctica

Caso Práctico: Limpieza Completa

Toma estudiantes_crudo.csv y déjalo listo para análisis, guardando el resultado en un nuevo archivo:

  • Carga el archivo con el separador correcto y revisa .info().
  • Cuenta los nulos por columna (isna().sum()) y muestra las filas afectadas.
  • Rellena la nota faltante con el promedio.
  • Muestra las filas duplicadas y luego elimínalas.
