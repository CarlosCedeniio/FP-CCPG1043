Agregaciones, Estadísticas y GroupBy

Unidad 06 · Clase 3

De la tabla fila a fila, a resúmenes por categoría con una sola línea de código.

Punto de Partida

Dataset ya Analizado

Seguimos con lo que dejamos en la clase anterior: estudiantes_analizado.csv, ya con nota_final y en_riesgo calculados.

import pandas as pd

df = pd.read_csv('estudiantes_analizado.csv')
print(df[['nombre', 'carrera', 'nota_final', 'asistencia']])

Ordenar

.sort_values()

orden = df.sort_values('nota_final', ascending=False)
print(orden[['nombre', 'nota_final']])
# Valentina  9.45
# Marcela    9.17
# Isabella   8.91

Ordenar

Varias Columnas e inplace

Puedes ordenar por varias columnas a la vez, cada una con su propio orden ascendente/descendente.

orden_multi = df.sort_values(
    ['carrera', 'nota_final'], ascending=[True, False]
)

inplace=True modifica el DataFrame original directamente y no devuelve nada — úsalo con cuidado, porque pierdes el orden original.

Tipos de Dato

Categóricos vs. No Categóricos

Categóricos

Un grupo/etiqueta de un conjunto limitado. Ej.: carrera. No tiene sentido sumarlos.

No Categóricos

Cantidades medibles. Ej.: nota_final, asistencia. Sí se pueden promediar/sumar.

A los categóricos les aplicamos conteos y agrupaciones; a los numéricos, estadísticas.

Explorar Categorías

unique(), value_counts(), isin()

print(df['carrera'].unique())
# ['ingeniería' 'administración' 'medicina' 'derecho' 'arquitectura']

print(df['carrera'].value_counts())
# ingeniería        3
# administración    2
# medicina          2

Explorar Categorías

Filtrar con .isin()

Filtra filas cuyo valor está dentro de una lista de opciones — evita encadenar varios |.

carreras = df[df['carrera'].isin(['ingeniería', 'medicina'])]
print(carreras[['nombre', 'carrera']])

Contenido Núcleo

.groupby(): Estadísticas por Categoría

.groupby('columna') agrupa las filas según sus valores, y luego aplicas una agregación a cada grupo por separado.

print(df.groupby('carrera')[['nota_final', 'asistencia']].mean().round(2))
#                 nota_final  asistencia
# carrera
# administración        7.48        86.0
# ingeniería            8.51        85.0
# medicina              9.31        98.5

GroupBy

Una Sola Columna del Grupo

print(df.groupby('carrera')['nota_final'].mean().round(2))

Con una sola línea obtuvimos el promedio por carrera — imposible de leer de un vistazo en la tabla original, fila por fila.

Extremos

nlargest() y nsmallest()

print(df.nlargest(3, 'nota_final')[['nombre', 'nota_final']])
print(df.nsmallest(3, 'nota_final')[['nombre', 'nota_final']])

El top-3 y el bottom-3, ya ordenados — sin necesidad de llamar .sort_values() primero.

GroupBy

.reset_index()

Al agrupar, la columna de agrupación pasa a ser el índice del resultado. Si prefieres tenerla de vuelta como columna común, usa .reset_index().

resumen = df.groupby('carrera')['nota_final'].mean().round(2).reset_index()
print(resumen)
#          carrera  nota_final
# 0 administración        7.48
# 1     arquitectura        6.50

Resumir

.apply()

Ejecuta una función propia sobre cada valor de una columna.

def clasificar(nota):
    if nota >= 9:
        return 'Excelente'
    elif nota >= 7.5:
        return 'Bueno'
    else:
        return 'Regular'

df['categoria'] = df['nota_final'].apply(clasificar)

Resumir

.agg(): Varias Agregaciones a la Vez

resumen = df.groupby('carrera')['nota_final'].agg(['mean', 'max', 'min', 'count']).round(2)
print(resumen)
#                 mean   max   min  count
# ingeniería      8.51  8.91  8.03      3
# medicina        9.31  9.45  9.17      2

Con .agg() obtienes, en un solo paso, un mini-reporte estadístico por carrera.
