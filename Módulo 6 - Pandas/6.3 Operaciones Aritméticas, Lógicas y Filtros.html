Combinar columnas, construir condiciones y quedarte solo con las filas que te interesan.

Retomamos

El Dataset Limpio

En la clase pasada dejamos un archivo limpio: estudiantes_limpio.csv. Lo usamos como punto de partida — limpiar una sola vez, analizar muchas veces.

import pandas as pd

df = pd.read_csv('estudiantes_limpio.csv')
print(df)
#       nombre         carrera  calificacion  asistencia
# 0        Ana      ingeniería          8.50          95
# 1       Luis  administración          7.20          80

Aritmética

Operaciones entre Series

Igual que con Numpy, las operaciones entre dos columnas se aplican fila por fila, automáticamente — sin ningún bucle for.

df['nota_final'] = (df['calificacion'] * 0.9 + (df['asistencia'] / 100) * 1.0).round(2)
print(df[['nombre', 'calificacion', 'asistencia', 'nota_final']])
#       nombre  calificacion  asistencia  nota_final
# 0        Ana          8.50          95        8.60
# 1       Luis          7.20          80        7.28

Ponderamos calificación (90%) y asistencia (10%) — sin recorrer fila por fila manualmente.

Lógica

Series Booleanas

Comparar una columna con un valor produce una Series de True/False, una por cada fila.

print(df['calificacion'] >= 8.0)
# 0     True
# 1    False
# 2     True
# 3     True

Esta Series booleana, por sí sola, ya nos dice quién cumple la condición. El siguiente paso natural es usarla para filtrar.

Filtros — Contenido Núcleo

& y |, no and / or

Para quedarte solo con las filas que cumplen una condición: df[condición]. Para combinar varias condiciones, se usan & (Y) y | (O) — cada condición entre paréntesis.

aprobados = df[df['calificacion'] >= 8.0]

# Y: calificación alta Y buena asistencia
buenos = df[(df['calificacion'] >= 8.0) & (df['asistencia'] >= 90)]

Filtros

Combinar con |

ing_o_med = df[(df['carrera'] == 'ingeniería') | (df['carrera'] == 'medicina')]
print(ing_o_med[['nombre', 'carrera']])
# Ana, Marcela, Pedro, Valentina, Isabella

El Porqué

and/or vs &/|

Incorrecto

df[df['a'] > 5 and df['b'] > 5]
# ValueError: The truth value
# of a Series is ambiguous

Correcto

df[(df['a'] > 5) & (df['b'] > 5)]
# Funciona: compara
# elemento a elemento

and/or esperan un único True/False, no una Series completa de valores.

Reemplazar

.mask(): Según una Condición

.mask(condición, valor) reemplaza con valor (o NaN si no se especifica) los elementos donde la condición es True. Es lo opuesto a un filtro: en vez de quedarte con lo que cumple, modificas lo que cumple.

print(df['calificacion'].mask(df['calificacion'] < 7.0, other=0))
# Todas las calificaciones igual, excepto Carlos (6.5 → 0)

Extremos

.idxmax() y .idxmin()

Devuelven el índice (la etiqueta de fila) donde está el valor máximo o mínimo — no el valor en sí, sino dónde está.

mejor = df['calificacion'].idxmax()
peor_asistencia = df['asistencia'].idxmin()

print(df.loc[mejor, 'nombre'])           # Valentina
print(df.loc[peor_asistencia, 'nombre']) # Carlos
