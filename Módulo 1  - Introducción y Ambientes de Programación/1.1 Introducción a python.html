El Origen de Python

Creado por Guido van Rossum y lanzado en 1991. Diseñado para ser un lenguaje potente pero extremadamente fácil de leer.

Dato curioso: Su nombre no proviene del reptil, sino del grupo cómico británico Monty Python's Flying Circus.

El "Zen" de Python

Principios de diseño que priorizan la claridad sobre la complejidad.

Compilado vs Interpretado

¿Cómo entiende la máquina nuestro código?

Compilador (Ej. C++)

Traduce todo el bloque antes de ejecutar. Más rápido en ejecución, más lento de probar.

Intérprete (Ej. Python)

Traduce y ejecuta línea por línea. Más amigable y rápido para desarrollo iterativo.

¿Dónde escribiremos código?

No necesitas comprar una súper computadora, usaremos la nube:

1. Online-Python

(Inicio del Curso)
Sitio web rápido (online-python.com). No requiere cuenta. Perfecto para lo básico.

2. Google Colab

(Segundo Parcial)
Cuadernos en la nube de Google. Mezcla texto explicativo con código. Ideal para Datos.

3. IDEs Profesionales

(Avanzado)
Programas como PyCharm o VS Code instalados localmente para sistemas grandes.

¿Cómo le hablamos a Python?

Tenemos dos formas principales de trabajar:

1. Modo Interactivo (REPL)

Escribimos una línea de código y Python responde de inmediato. Perfecto para probar ideas rápidamente.

2. Scripts (Archivos)

Escribimos todas las instrucciones en un archivo de texto (.py) y le decimos a Python que las ejecute de golpe.

Los Errores son Normales

Al aprender un nuevo idioma, es común equivocarse. En Python, eso genera un SyntaxError.

Importante: Un error no romperá tu computadora. Solo significa que Python no entendió la instrucción y te pide corregirla.
