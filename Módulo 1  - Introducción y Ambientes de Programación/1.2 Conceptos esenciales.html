Entendiendo la anatomía de un programa en Python: reglas de escritura, el poder de la identación y la comunicación mediante comentarios.

La Regla de Oro: Identación

A diferencia de otros lenguajes que usan llaves { }, Python utiliza el espacio en blanco para definir la estructura del código.

Legibilidad Forzada

Si el código no está bien alineado, Python simplemente no lo ejecutará.

Estándar PEP 8

Se recomienda usar 4 espacios por cada nivel de jerarquía.

Visualizando la Identación

El "margen" indica qué instrucciones pertenecen a un bloque.

# Ejemplo de estructura visual
if es_estudiante_espol:
    print("Bienvenido al campus")
    if tiene_carnet:
        print("Puedes entrar a la biblioteca")
print("Fin del proceso") # Fuera del bloque

Palabras Reservadas

Son términos que Python utiliza para sus funciones internas. No puedes usarlas como nombres de tus variables.

Categoría Ejemplos Uso

Comentarios: El Manual Interno

¿Por qué comentar?

Para explicar el por qué de un código complejo, no el qué. Útil para tu "yo del futuro" o tus compañeros de equipo.

# Esto es un comentario de una línea
print("Hola ESPOL")

"""
Este es un comentario
de múltiples líneas o 
docstring.
"""
