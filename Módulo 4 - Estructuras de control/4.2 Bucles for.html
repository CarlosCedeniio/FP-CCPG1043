Bucles for

Unidad 04

Iterar sobre rangos y colecciones con for, buscar valores extremos y construir listas sin repetidos.

Repetir sin Copiar y Pegar

¿Por qué iterar?

Sin for

print("Línea 1")
print("Línea 2")
print("Línea 3")
print("Línea 4")
print("Línea 5")
# ¿Y si fueran 1000?

Con for

for i in range(1, 6):
    print(f"Línea {i}")

# Funciona para 5 o 5000

for variable in range(n): repite el bloque n veces. La variable toma cada valor de la secuencia.

for in range

Variantes de range

# range(stop) → 0, 1, 2, ..., stop-1
for i in range(5):
    print(i)          # 0 1 2 3 4

# range(start, stop) → start, start+1, ..., stop-1
for i in range(2, 6):
    print(i)          # 2 3 4 5

# range(start, stop, step) → de start a stop, de step en step
for i in range(0, 11, 2):
    print(i)          # 0 2 4 6 8 10

Iterar sobre Datos

for in colección

El for puede recorrer directamente una lista. La variable toma el valor de cada elemento, uno por uno.

notas = [8.5, 6.0, 9.2, 7.4, 5.8]

# Recorrer e imprimir
for nota in notas:
    print(nota)

# Acumular una suma
total = 0
for nota in notas:
    total = total + nota

promedio = total / len(notas)
print(f"Promedio: {promedio}")

Índice y Valor

for in enumerate

enumerate(colección) entrega pares (índice, elemento). Útil cuando se necesita saber la posición.

estudiantes = ["Ana", "Luis", "María", "Carlos"]

for i, nombre in enumerate(estudiantes):
    print(f"{i}: {nombre}")
# 0: Ana
# 1: Luis
# 2: María
# 3: Carlos

# Encontrar la posición de un nombre
for i, nombre in enumerate(estudiantes):
    if nombre == "María":
        print(f"María está en la posición {i}")

Recorrer para Comparar

Mayor y menor (sin empate)

Patrón: inicializar con el primer elemento, luego comparar cada elemento contra el candidato actual.

numeros = [4, 7, 2, 9, 1, 5]

mayor = numeros[0]
menor = numeros[0]

for n in numeros:
    if n > mayor:
        mayor = n
    if n < menor:
        menor = n

print(f"Mayor: {mayor}")   # 9
print(f"Menor: {menor}")   # 1

Recorrer para Comparar

Mayor y menor (con empates)

Cuando puede haber empates, se guarda una lista de valores empatados. Se reinicia la lista si aparece un nuevo máximo.

notas = [9.0, 7.5, 9.0, 8.0, 9.0, 6.5]

mayor = notas[0]
empatados = [notas[0]]

for nota in notas:
    if nota > mayor:
        mayor = nota
        empatados = [nota]      # nuevo máximo: reiniciar lista
    elif nota == mayor:
        empatados.append(nota)  # empate: agregar a la lista

print(f"Nota máxima: {mayor}")
print(f"Ocurrencias: {len(empatados)}")

Construir sin Duplicar

Lista sin repetidos

Estrategia: construir una nueva lista agregando solo los elementos que aún no están en ella. Preserva el orden de aparición.

colores = ["rojo", "azul", "rojo", "verde", "azul", "rojo"]

unicos = []
for color in colores:
    if color not in unicos:
        unicos.append(color)

print(unicos)   # ["rojo", "azul", "verde"]

# El operador 'in' verifica pertenencia en la lista

Bucles dentro de Bucles

for anidado

El bucle interior se ejecuta por completo en cada iteración del bucle exterior.

# Tabla de multiplicar 3×3
for fila in range(1, 4):
    for col in range(1, 4):
        print(f"{fila} × {col} = {fila * col}")
    print("---")

# 1 × 1 = 1  |  1 × 2 = 2  |  1 × 3 = 3
# ---
# 2 × 1 = 2  |  2 × 2 = 4  |  2 × 3 = 6
# ...

Forma Compacta

List comprehension

Una list comprehension expresa en una línea lo que un for con append hace en varias. Solo usar si se entiende bien la forma larga.

Forma larga

cuadrados = []
for n in range(1, 6):
    cuadrados.append(n ** 2)
# [1, 4, 9, 16, 25]

List comprehension

cuadrados = [n ** 2
             for n in range(1, 6)]
# [1, 4, 9, 16, 25]

Regla: si no puedes escribir la versión con for y append primero, no uses la comprehension.
