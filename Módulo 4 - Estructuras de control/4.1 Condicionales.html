Condicionales

Unidad 04

Cómo hacer que un programa tome decisiones: if, if-else e if-elif-else.

Tomar Decisiones

La estructura if

El bloque if ejecuta su cuerpo solo si la condición es True. Si es False, se ignora por completo.

nota = 8.5

if nota >= 7.0:
    print("Aprobado")

# Si nota fuera 5.0, no se imprimiría nada

La indentación de 4 espacios delimita el bloque. Todo lo que esté indentado pertenece al if.

Dos Caminos

if-else

else define qué hacer cuando la condición es False. Exactamente uno de los dos bloques siempre se ejecuta.

edad = 16

if edad >= 18:
    print("Mayor de edad")
else:
    print("Menor de edad")

# Con edad = 16  →  "Menor de edad"
# Con edad = 20  →  "Mayor de edad"

Múltiples Caminos

if-elif-else

elif agrega ramas intermedias. Python las evalúa en orden y ejecuta solo la primera que sea True.

nota = 8.0

if nota >= 9.0:
    print("A — Sobresaliente")
elif nota >= 7.0:
    print("B — Aprobado")
elif nota >= 5.0:
    print("C — Suficiente")
else:
    print("D — Reprobado")

# nota = 8.0  →  "B — Aprobado"

Combinando Condiciones

Condiciones compuestas

def es_mayor_de_edad(edad):
    return edad >= 18

def tiene_membresia(usuario):
    return usuario in ["Ana", "Luis", "María"]

usuario = "Ana"
edad    = 20

# and: ambas condiciones deben ser True
if es_mayor_de_edad(edad) and tiene_membresia(usuario):
    print("Acceso completo")
elif es_mayor_de_edad(edad):
    print("Acceso básico (sin membresía)")
else:
    print("Acceso denegado")

Usar funciones booleanas como condiciones hace el código más legible y reutilizable.

Estructuras Anidadas

if dentro de if

Se puede colocar un if dentro del bloque de otro if. Útil cuando la segunda condición solo tiene sentido si la primera ya es True.

puntaje = 85
asistencia = 0.90

if puntaje >= 60:
    if asistencia >= 0.75:
        print("Aprobado")
    else:
        print("Reprobado por inasistencia")
else:
    print("Reprobado por puntaje")

Cuando ambas condiciones son independientes, a veces es más claro usar and directamente en un solo if.

Errores Clásicos

= vs == y los dos puntos

Incorrecto

# = asigna, no compara
if x = 10:
    print("es diez")
# SyntaxError

# Falta los dos puntos
if x == 10
    print("es diez")
# SyntaxError

Correcto

# == compara valores
if x == 10:
    print("es diez")

# Siempre termina con :
if x == 10:
    print("es diez")
