Bucle while

Unidad 04

Repetir mientras una condición sea verdadera. Condiciones expresivas, funciones booleanas, sin banderas.

Repetir hasta que…

La estructura while

El while ejecuta su bloque repetidamente, mientras la condición sea True. A diferencia del for, no sabemos de antemano cuántas veces iterará.

contador = 1

while contador <= 5:
    print(f"Vuelta {contador}")
    contador = contador + 1

# Vuelta 1
# Vuelta 2
# ...
# Vuelta 5

El cuerpo del bucle debe modificar algo que afecte la condición. Si no, el bucle nunca termina.

El Peligro Principal

Bucle infinito

Infinito

La condición nunca cambia a False: el programa se congela.

x = 1
while x > 0:
    print(x)
    # x nunca se modifica
    # ← bucle infinito

Terminable

El cuerpo actualiza la variable que controla la condición.

x = 1
while x <= 5:
    print(x)
    x = x + 1
    # x crece → llega a 6
    # → condición False → para

Anti-patrón

El problema con las banderas

Con bandera — evitar

La variable encontrado es redundante: el índice ya contiene toda la información necesaria.

lista  = [3, 7, 1, 9, 4]
objetivo = 9
i = 0
encontrado = False           # ← bandera innecesaria

while not encontrado:
    if lista[i] == objetivo:
        encontrado = True    # ← solo sirve para parar
    i = i + 1

print(f"Encontrado en posición {i - 1}")

Estrategia 1

Condición directa y compuesta

Sin bandera — correcto

La condición del while expresa directamente cuándo continuar: mientras no se haya encontrado Y no se haya salido de la lista.

lista    = [3, 7, 1, 9, 4]
objetivo = 9
i = 0

while i < len(lista) and lista[i] != objetivo:
    i = i + 1

if i < len(lista):
    print(f"Encontrado en posición {i}")
else:
    print("No encontrado")

Estrategia 2

Función booleana como condición

Cuando la condición es compleja o reutilizable, definir una función booleana y usarla directamente en el while hace el código más claro.

def es_valido(numero):
    return numero > 0 and numero <= 100

numero = int(input("Ingresa un número (1–100): "))

while not es_valido(numero):
    print("Valor fuera de rango.")
    numero = int(input("Intenta nuevamente: "))

print(f"Número aceptado: {numero}")

La función es_valido puede reutilizarse en cualquier parte del programa sin repetir la lógica.

Estructuras Anidadas

while con for interno

Se puede combinar un while externo con un for interno cuando la cantidad de grupos es variable pero el procesamiento de cada grupo es fijo.

def todos_aprobados(notas):
    for nota in notas:
        if nota < 7.0:
            return False
    return True

grupos = [[8.0, 9.1, 7.5], [6.5, 8.0], [9.0, 7.0]]
i = 0

while i < len(grupos) and todos_aprobados(grupos[i]):
    print(f"Grupo {i}: todos aprobados")
    i = i + 1

print(f"Primer grupo con reprobado: {i}")

¿Cuándo Usar Cada Uno?

while vs for

Usa for cuando…

Sabes de antemano cuántas veces iterar, o tienes una colección que recorrer completa.

for nota in notas:
    procesar(nota)

for i in range(10):
    simular_turno(i)

Usa while cuando…

Iteras hasta que ocurra una condición que no depende de un conteo fijo.

while not es_valido(dato):
    dato = pedir_dato()

while saldo > 0 and deuda > 0:
    pagar_cuota()
