## Descripción

El departamento de registro de una universidad almacena la información de cada estudiante en un único string con el siguiente formato:

```
"YYYY-FACULTAD-NUMERO-GENERO"
```

Donde:
- `YYYY` — año de ingreso (4 dígitos)
- `FACULTAD` — siglas de la facultad (ej: `FIEC`, `FIMCP`, `EDCOM`)
- `NUMERO` — número de matrícula con 3 dígitos (ej: `047`)
- `GENERO` — una letra: `M` (masculino) o `F` (femenino)

Escribe un script que:

1. Pida al usuario ingresar un código de matrícula.
2. Use `.split("-")` para separar las partes del código.
3. Con condicionales, imprima un reporte con el siguiente formato:

```
--- REPORTE DE ESTUDIANTE ---
Año de ingreso : 2023
Facultad       : FIEC
Matrícula Nro  : 047
Bienvenida, estudiante de FIEC.
Categoría      : Estudiante reciente
```

Las reglas para el reporte son:
- El saludo debe ser `"Bienvenido"` si el género es `M`, o `"Bienvenida"` si es `F`.
- La categoría es `"Estudiante antiguo"` si el año de ingreso es menor a 2022, o `"Estudiante reciente"` si es 2022 o posterior.

## Ejemplo de interacción

```
Ingrese el código de matrícula: 2019-FIMCP-013-M

--- REPORTE DE ESTUDIANTE ---
Año de ingreso : 2019
Facultad       : FIMCP
Matrícula Nro  : 013
Bienvenido, estudiante de FIMCP.
Categoría      : Estudiante antiguo
```

## Restricciones

- Usa `.split("-")` para separar el código; no uses slicing manual.
- Convierte el año a entero con `int()` para compararlo en el condicional de categoría.
- No uses funciones; resuélvelo con código secuencial y condicionales.
