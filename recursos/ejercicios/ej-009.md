## Descripción

Crea un script para generar credenciales temporales para nuevos empleados. El sistema solicita el nombre y año de nacimiento del empleado, y le asigna un departamento y un código de acceso de forma aleatoria.

El equipo de seguridad ya desarrolló una función llamada `generar_codigo_aleatorio()`. **Asume que funciona correctamente, no necesitas escribirla** — solo debes llamarla. La función no recibe parámetros y devuelve un string (ej: `"AX-34B"`).

Define esta lista en tu script:

```python
departamentos = ["Sistemas", "Recursos Humanos", "Ventas", "Marketing"]
```

**Crea una función llamada `crear_credencial(nombre_completo, anio_nacimiento)`** donde:

- `nombre_completo` es un string con el nombre del empleado.
- `anio_nacimiento` es un int con el año de nacimiento.

La función debe:

1. Seleccionar aleatoriamente un departamento de la lista `departamentos`.
2. Llamar a `generar_codigo_aleatorio()` para obtener el código de acceso.
3. Retornar un único string con el siguiente formato exacto (usando f-strings y `\n` para los saltos de línea):

```
--- CREDENCIAL GENERADA ---
Empleado: Ana Torres
Año de Nacimiento: 1995
Departamento: Marketing
Código de Acceso: AX-34B
```

Finalmente, solicita los datos al usuario e imprime el resultado de llamar a `crear_credencial()`.

## Ejemplo de interacción

```
Ingrese el nombre del empleado: Ana Torres
Ingrese el año de nacimiento: 1995

--- CREDENCIAL GENERADA ---
Empleado: Ana Torres
Año de Nacimiento: 1995
Departamento: Marketing
Código de Acceso: AX-34B
```

## Restricciones

- Toda la lógica de construcción del string debe estar dentro de `crear_credencial()`.
- La función debe **retornar** el string, no imprimirlo directamente.
- El `print()` debe hacerse fuera de la función, en el programa principal.
- No modifiques ni escribas `generar_codigo_aleatorio()`, solo llámala.
