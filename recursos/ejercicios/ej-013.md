## Descripción

Escribe un script que simule lanzar un dado de 6 caras varias veces. El programa debe:

1. Pedir al usuario cuántas veces quiere lanzar el dado.
2. Usar un `for` para iterar esa cantidad de veces.
3. En cada iteración, generar un número aleatorio entre **1 y 6**.
4. Usar un condicional para clasificar cada resultado:
   - 1 o 2 → `"bajo"`
   - 3 o 4 → `"medio"`
   - 5 o 6 → `"alto"`
5. Imprimir cada lanzamiento con su clasificación.
6. Al finalizar, imprimir cuántos resultados cayeron en cada categoría.

## Ejemplo de interacción

```
¿Cuántas veces quieres lanzar el dado? 6

Lanzamiento 1: 3  → medio
Lanzamiento 2: 6  → alto
Lanzamiento 3: 1  → bajo
Lanzamiento 4: 4  → medio
Lanzamiento 5: 6  → alto
Lanzamiento 6: 2  → bajo

--- RESUMEN ---
Bajos : 2
Medios: 2
Altos : 2
```

## Restricciones

- Usa `random.randint(1, 6)` para simular el dado.
- Usa un único `for` con `range()` para iterar; no uses `while`.
- Lleva el conteo de cada categoría con variables que inicializas en `0` antes del ciclo.
- No uses listas ni funciones; resuélvelo de forma secuencial.
