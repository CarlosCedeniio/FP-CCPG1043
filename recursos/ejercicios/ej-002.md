## Descripción

Escribe una función llamada `generar_contrasena` que reciba un parámetro `longitud` (entero) y retorne una contraseña aleatoria formada por caracteres de las siguientes categorías:

- Letras minúsculas: `abcdefghijklmnopqrstuvwxyz`
- Letras mayúsculas: `ABCDEFGHIJKLMNOPQRSTUVWXYZ`
- Dígitos: `0123456789`
- Símbolos: `!@#$%^&*`

La contraseña generada **debe incluir al menos un carácter de cada categoría**. Los demás caracteres se eligen aleatoriamente del conjunto completo.

## Ejemplo de entrada / salida

```
Entrada:  longitud = 8
Salida:   "aB3!xK9m"   ← (variará cada ejecución)

Entrada:  longitud = 12
Salida:   "Xp2@qN8!wR5z"   ← (variará cada ejecución)
```

## Restricciones

- Usa el módulo `random` de la biblioteca estándar de Python.
- La función solo debe recibir `longitud` como argumento.
- Si `longitud` es menor a 4, lanza un `ValueError` con el mensaje `"La longitud mínima es 4"`.
- No uses librerías externas como `secrets` o `string` (construye los conjuntos de caracteres tú mismo).

## Pista

Puedes usar `random.choice(cadena)` para elegir un carácter aleatorio de una cadena. Para mezclar una lista de caracteres, usa `random.shuffle(lista)`.
