## Descripción

Escribe un script que simule las notas finales de un salón de clases generándolas de forma aleatoria. El programa debe:

1. Pedir al usuario la cantidad de estudiantes.
2. Usar un `for` para iterar esa cantidad de veces.
3. En cada iteración, generar una nota entera aleatoria entre **0 y 10**.
4. Usar un condicional para determinar si el estudiante **aprobó** (nota >= 7) o **reprobó** (nota < 7).
5. Imprimir cada resultado en el formato mostrado abajo.
6. Al terminar el ciclo, imprimir el resumen final.

## Ejemplo de interacción

```
¿Cuántos estudiantes hay en el salón? 5

Estudiante 1: nota = 8  → Aprobado
Estudiante 2: nota = 4  → Reprobado
Estudiante 3: nota = 7  → Aprobado
Estudiante 4: nota = 2  → Reprobado
Estudiante 5: nota = 9  → Aprobado

--- RESUMEN ---
Total aprobados : 3
Total reprobados: 2
```

## Restricciones

- Usa `random.randint(0, 10)` para generar cada nota.
- Usa un único `for` con `range()` para iterar; no uses `while`.
- Lleva el conteo de aprobados y reprobados con variables que inicializas en `0` antes del ciclo.
- No uses listas ni funciones; resuélvelo de forma secuencial.
