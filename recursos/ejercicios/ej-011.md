## Descripción

Un almacén registra cada producto en un string con el siguiente formato:

```
"CATEGORIA-CODIGO-ESTADO-STOCK"
```

Donde:
- `CATEGORIA` — tipo de producto (ej: `ELEC`, `ROPA`, `ALIM`)
- `CODIGO` — identificador numérico de 3 dígitos (ej: `042`)
- `ESTADO` — puede ser `ACTIVO` o `INACTIVO`
- `STOCK` — cantidad disponible en unidades (número entero)

Debes crear **tres funciones** y un programa principal que las use:

---

**`parsear_producto(codigo)`**
Recibe el string del producto, usa `.split("-")` y retorna una tupla con los cuatro valores ya procesados:
```python
(categoria, codigo_id, estado, stock)
# stock debe ser entero (int)
```

---

**`clasificar_stock(cantidad)`**
Recibe la cantidad como entero y retorna un string según estas reglas:

| Cantidad | Retorna |
|---|---|
| 0 | `"agotado"` |
| 1 – 9 | `"crítico"` |
| 10 – 29 | `"bajo"` |
| 30 o más | `"normal"` |

---

**`es_producto_valido(estado, cantidad)`**
Recibe el estado (string) y la cantidad (int). Retorna `True` si el estado es `"ACTIVO"` **y** la cantidad es mayor a 0. En cualquier otro caso retorna `False`.

---

**Programa principal:**
1. Pide al usuario ingresar el código del producto.
2. Llama a `parsear_producto()` para obtener los datos.
3. Llama a `clasificar_stock()` y a `es_producto_valido()`.
4. Imprime el siguiente reporte:

```
--- REPORTE DE PRODUCTO ---
Categoría  : ELEC
Código     : 042
Estado     : ACTIVO
Stock      : 15 unidades  [bajo]
Disponible : Sí
```

El campo `Disponible` muestra `"Sí"` si `es_producto_valido()` retorna `True`, o `"No"` si retorna `False`.

## Ejemplo de interacción

```
Ingrese el código del producto: ROPA-007-INACTIVO-0

--- REPORTE DE PRODUCTO ---
Categoría  : ROPA
Código     : 007
Estado     : INACTIVO
Stock      : 0 unidades  [agotado]
Disponible : No
```

## Restricciones

- Cada función debe hacer **una sola tarea** (no mezcles lógica entre ellas).
- `parsear_producto()` debe usar `.split("-")`; no uses índices manuales sobre el string original.
- Las funciones deben **retornar** valores, no imprimirlos.
- Todo el `print()` debe estar en el programa principal.
