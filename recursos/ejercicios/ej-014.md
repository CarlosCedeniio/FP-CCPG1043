## Descripción

Crea un diccionario llamado `producto` con las claves `"nombre"`, `"precio"` y `"stock"`, usando los valores `"Teclado"`, `25.5` y `12` respectivamente.

Luego escribe un programa que:

1. Imprima el nombre y el precio accediendo con corchetes `[]`.
2. Aumente el `"stock"` en 10 unidades.
3. Use `.get()` para leer una clave `"categoria"` (que no existe en el diccionario), mostrando `"Sin categoría"` como valor por defecto si no se encuentra.
4. Imprima el diccionario `producto` completo al final.

## Ejemplo de entrada / salida

```
Salida:
Producto: Teclado — $25.5
Categoría: Sin categoría
{'nombre': 'Teclado', 'precio': 25.5, 'stock': 22}
```

## Restricciones

- No uses `.pop()` ni `del` en este ejercicio.
- El aumento de stock debe hacerse reasignando la clave (`producto["stock"] = ...`), no creando un diccionario nuevo.

## Pista

`producto["categoria"]` lanzaría un `KeyError` porque esa clave no existe — por eso se usa `.get("categoria", "Sin categoría")`.
