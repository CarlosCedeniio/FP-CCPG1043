## Descripción

Dado el siguiente código, responde las preguntas **sin ejecutarlo** — analiza paso a paso qué valor toma cada variable.

```python
lista_a = ["10", "20", "30", "40"]
lista_b = lista_a[:]
opciones = ["alfa", "beta", "gamma"]

seleccion = opciones[1]

parte_1 = seleccion.upper()[0:2]
parte_2 = lista_a[1]
parte_3 = str(len(seleccion) * int(lista_a[0]))

resultado_final = parte_1 + "_" + parte_2 + "_" + parte_3

print(resultado_final)
```

## Preguntas

1. ¿Cuál es el valor final de la variable `parte_1`?

2. ¿Cuál es el valor final de la variable `parte_2`?

3. ¿Cuál es el valor final de la variable `parte_3`?

4. ¿Qué imprime por pantalla el código?

## Restricciones

- Responde sin ejecutar el código.
- Justifica brevemente cada respuesta indicando qué operación produce ese resultado.
