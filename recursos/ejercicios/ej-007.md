## Descripción

Analiza el siguiente código **sin ejecutarlo** y responde la pregunta.

```python
import random

def saludo_aleatorio():
    nombres = ["Ana", "Carlos", "Luisa"]
    saludos = ["¡Hola!", "¿Qué tal?", "¡Bienvenid@!"]

    nombre_elegido = random.choice(nombres)
    saludo_elegido = random.choice(saludos)

    return f"{saludo_elegido} {nombre_elegido}."

print(saludo_aleatorio())
```

## Pregunta

¿Cuál de las siguientes opciones es una salida **IMPOSIBLE** para el código mostrado?

- a) `¡Hola! Ana.`
- b) `¿Qué tal? Carlos.`
- c) `¡Bienvenid@! Luisa.`
- d) `¡Hola! ¿Qué tal?.`

## Restricciones

- Justifica tu respuesta explicando por qué esa salida no puede ocurrir con este código.
- Considera exactamente qué valores puede tomar cada variable (`nombre_elegido` y `saludo_elegido`).
