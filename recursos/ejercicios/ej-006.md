## Descripción

Crea un programa que determine si un asistente puede ingresar a un evento. El programa debe verificar la edad, si el nombre está en la lista de invitados y si tiene un código de vestimenta adecuado.

Define estas listas al inicio de tu script:

```python
lista_invitados = ["Ana", "LUIS", "CarlOS", "David"]
codigos_vestimenta = ["formal", "etiqueta", "gala"]
```

## Requisitos

**1. Solicitar datos al usuario:**
- Nombre completo
- Edad (como número)
- Código de vestimenta (una sola palabra, ej: `formal`, `casual`, `gala`)

**2. Procesar los datos:**
- Convertir la edad a entero con `int()`.
- Limpiar el nombre: quitar espacios con `.strip()` y convertir a minúsculas con `.lower()` para comparar. Guarda también el nombre original para usarlo en los mensajes.
- Convertir el código de vestimenta a minúsculas. Guarda también el valor original para los mensajes.

**3. Lógica de acceso — el ingreso se permite solo si se cumplen las 3 condiciones:**
- **Condición 1 — Edad:** el asistente debe tener 18 años o más.
- **Condición 2 — Acceso:** el nombre normalizado debe estar en `lista_invitados` (normalizada también) **O** el código de vestimenta debe ser `"gala"` (pase especial).
- **Condición 3 — Vestimenta:** el código de vestimenta debe estar en `codigos_vestimenta`.

**4. Mensajes de salida con f-strings:**

| Caso | Mensaje |
|---|---|
| Menor de edad | `f"Lo sentimos, {nombre_original}. Eres menor de edad y no puedes ingresar."` |
| Vestimenta inválida | `f"Acceso denegado, {nombre_original}. El código de vestimenta '{vestimenta_original}' no es válido para este evento."` |
| No está en la lista | `f"Acceso denegado, {nombre_original}. No estás en la lista de invitados."` |
| Acceso permitido | `f"¡Bienvenido/a, {nombre_original.title()}! Disfruta del evento."` |

## Ejemplo de interacción

```
Ingrese su nombre: luis
Ingrese su edad: 25
Ingrese su código de vestimenta: formal

¡Bienvenido/a, Luis! Disfruta del evento.
```

```
Ingrese su nombre: Pedro
Ingrese su edad: 17
Ingrese su código de vestimenta: gala

Lo sentimos, Pedro. Eres menor de edad y no puedes ingresar.
```

## Restricciones

- El orden de verificación importa: primero edad, luego vestimenta, luego lista de invitados.
- Al comparar el nombre con `lista_invitados`, normaliza ambos lados a minúsculas.
- No uses `break`, funciones ni estructuras que no se hayan visto en el curso.
