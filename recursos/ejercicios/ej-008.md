## Descripción

Analiza el siguiente código **sin ejecutarlo** y responde la pregunta.

```python
def crear_perfil(nombre, edad, rol="Profesor"):
    status = rol == "Estudiante"
    edad_futura = edad + 1

    return f"Usuario: {nombre}, Edad prox: {edad_futura}, Status: {status}"

nombre_usuario = "David"
edad_usuario = 25

print(crear_perfil(nombre_usuario, edad_usuario))
```

## Pregunta

¿Cuál es la salida del código?

- a) `Usuario: David, Edad prox: 25, Status: True`
- b) `Usuario: nombre_usuario, Edad prox: 26, Status: Estudiante`
- c) `Usuario: David, Edad prox: 26, Status: False`
- d) `Usuario: David, Edad prox: 26, Status: Profesor`

## Restricciones

- Justifica tu respuesta indicando qué valor toma cada variable dentro de la función (`status`, `edad_futura`) y por qué.
- Presta atención al valor del parámetro `rol` cuando la función es llamada sin ese argumento.
