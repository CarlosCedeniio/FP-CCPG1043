## Descripción

Tienes un diccionario `calificaciones` donde cada clave es el nombre de un estudiante y cada valor es su nota final (un número entre 0 y 10).

Escribe una función `agrupar_por_rango(calificaciones)` que devuelva un **diccionario anidado** con tres claves fijas — `"aprobado"`, `"en_riesgo"` y `"reprobado"` — donde cada una contenga la **lista** de nombres de los estudiantes que caen en ese rango, según:

- Nota `>= 7.0` → `"aprobado"`
- Nota `>= 5.0` y `< 7.0` → `"en_riesgo"`
- Nota `< 5.0` → `"reprobado"`

## Ejemplo de entrada / salida

```
Entrada:  {'Ana': 9.5, 'Luis': 6.0, 'Eva': 9.5, 'Pedro': 4.0, 'Marta': 5.5}
Salida:   {
    'aprobado':  ['Ana', 'Eva'],
    'en_riesgo': ['Luis', 'Marta'],
    'reprobado': ['Pedro']
}
```

## Restricciones

- El diccionario de resultado siempre debe tener las tres claves (`"aprobado"`, `"en_riesgo"`, `"reprobado"`), incluso si alguna lista queda vacía.
- El orden de los nombres dentro de cada lista debe respetar el orden en que aparecen en `calificaciones`.

## Pista

Inicializa el diccionario resultado con las tres claves apuntando a listas vacías. Luego recorre `calificaciones.items()` y usa condicionales para decidir a qué lista, dentro del diccionario anidado, agregar cada nombre con `.append()`.
