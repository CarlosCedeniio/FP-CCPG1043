## Descripción

Tienes una lista de notas de estudiantes (valores enteros entre 0 y 100). Escribe un programa que realice las siguientes operaciones:

1. **Filtrar** las notas aprobadas (nota >= 60) y las reprobadas (nota < 60) en dos listas separadas.
2. **Ordenar** cada lista de mayor a menor (sin usar el método `.sort()` ni `sorted()` — implementa tu propio algoritmo de ordenamiento).
3. **Calcular el promedio** de las notas aprobadas y el promedio de las notas reprobadas.
4. **Imprimir** los resultados con el siguiente formato:

```
Aprobados (N): [nota1, nota2, ...]  — Promedio: XX.X
Reprobados (N): [nota1, nota2, ...] — Promedio: XX.X
```

## Ejemplo de entrada / salida

```python
notas = [72, 45, 91, 58, 60, 83, 34, 77, 60, 49]
```

```
Aprobados (5): [91, 83, 77, 72, 60]  — Promedio: 76.6
Reprobados (5): [58, 49, 45, 34, 0]  — Promedio: 37.2
```

*(Nota: el 0 es solo si la lista tiene un cero; el ejemplo es ilustrativo.)*

## Restricciones

- No uses `.sort()`, `sorted()`, ni ninguna función de ordenamiento incorporada. Implementa el ordenamiento con un bucle `for` o `while`.
- El promedio debe mostrarse con **un decimal** (usa `round()` o formato `:.1f`).
- Si una de las listas está vacía, imprime `"Sin aprobados"` o `"Sin reprobados"` según corresponda.

## Pista

El algoritmo de **burbuja (bubble sort)** es uno de los más sencillos: recorre la lista comparando pares adyacentes e intercambiándolos si están en el orden incorrecto. Repite hasta que no haya intercambios.
