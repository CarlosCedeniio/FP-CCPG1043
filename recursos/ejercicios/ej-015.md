## Descripción

Escribe una función `contar_palabras(texto)` que reciba un string y devuelva un diccionario donde cada clave sea una palabra del texto y cada valor sea la cantidad de veces que esa palabra aparece.

La comparación debe ignorar mayúsculas/minúsculas y los signos de puntuación básicos (`,` y `.`) no deben formar parte de las palabras contadas.

## Ejemplo de entrada / salida

```
Entrada:  "Este es un texto de ejemplo. Un texto simple para probar el ejemplo."
Salida:   {'este': 1, 'es': 1, 'un': 2, 'texto': 2, 'de': 1, 'ejemplo': 2,
           'simple': 1, 'para': 1, 'probar': 1, 'el': 1}
```

## Restricciones

- No uses librerías externas (por ejemplo `collections.Counter`); resuélvelo iterando manualmente.
- El orden de las claves en el diccionario resultante no importa.

## Pista

Convierte el texto a minúsculas y elimina la puntuación con `.replace(",", "").replace(".", "")` antes de dividirlo en palabras con `.split()`. Luego recorre esa lista de palabras: si la palabra ya está en el diccionario, suma 1 a su valor con `.get()`; si no, agrégala con valor 1.
