Una Nueva Colección

¿Qué es un Diccionario?

Imagina una agenda telefónica: cada nombre tiene asociado un número. Un diccionario en Python funciona igual — guarda datos como pares clave: valor.

  • Son colecciones desordenadas de elementos.
  • Cada clave es única y sirve para acceder a su valor.
  • Son mutables: se pueden añadir, modificar o eliminar elementos.

La Sintaxis

Llaves y pares clave-valor

Se definen con llaves { } y pares clave: valor separados por comas.

mi_diccionario = {
    "clave1": "valor1",
    "clave2": "valor2",
    "clave3": "valor3"
}

La clave debe ser un dato inmutable (string, número). El valor puede ser de cualquier tipo, incluso otra lista o diccionario.

Creación de Diccionarios

Diccionarios vacíos

Se puede crear un diccionario vacío y añadir elementos después, con {} o con dict().

diccionario_vacio = {}
# O también
diccionario_vacio = dict()

Creación de Diccionarios

Con datos iniciales

persona = {
    "nombre": "Ana",
    "edad": 30,
    "ciudad": "Madrid"
}

productos = {
    101: "Laptop",
    102: "Mouse",
    103: "Teclado"
}

Las claves no tienen que ser strings — en productos son números enteros usados como código.

Acceso a Elementos

Acceso directo con []

Se accede a un valor usando su clave entre corchetes [ ].

persona = {"nombre": "Ana", "edad": 30}

print(persona["nombre"])  # Ana
print(persona["edad"])    # 30

¡Cuidado! Si la clave no existe, Python lanza un KeyError.

Acceso a Elementos

Acceso seguro con .get()

Para evitar el KeyError, usa .get(). Devuelve None — o un valor por defecto — si la clave no existe.

persona = {"nombre": "Ana", "edad": 30}

print(persona.get("nombre"))               # Ana
print(persona.get("telefono"))             # None
print(persona.get("pais", "Desconocido"))  # Desconocido

Diccionarios Mutables

Añadir y modificar elementos

Añadir un nuevo par

persona = {"nombre": "Ana"}
persona["edad"] = 30
print(persona)
# {'nombre': 'Ana', 'edad': 30}

Modificar un valor

persona = {"nombre": "Ana", "edad": 30}
persona["edad"] = 31
print(persona)
# {'nombre': 'Ana', 'edad': 31}

La misma sintaxis diccionario[clave] = valor sirve para añadir (si la clave no existe) o modificar (si ya existe).

Eliminar Elementos

del y .pop()

del

persona = {"nombre": "Ana", "edad": 30}
del persona["edad"]
print(persona)
# {'nombre': 'Ana'}

.pop()

persona = {"nombre": "Ana", "edad": 30}
edad = persona.pop("edad")
print(edad)      # 30
print(persona)   # {'nombre': 'Ana'}

.pop() elimina el par y además devuelve el valor eliminado — útil cuando lo necesitas antes de descartarlo.

Eliminar Elementos

.clear()

Elimina todos los elementos, dejando el diccionario vacío.

diccionario = {"a": 1, "b": 2}
diccionario.clear()
print(diccionario)  # {}

Explorando el Contenido

.keys(), .values(), .items()

  • .keys() — vista con todas las claves.
  • .values() — vista con todos los valores.
  • .items() — vista con pares clave-valor como tuplas.
estudiante = {"nombre": "Luis", "carrera": "Sistemas", "id": 123}

print(estudiante.keys())    # dict_keys(['nombre', 'carrera', 'id'])
print(estudiante.values())  # dict_values(['Luis', 'Sistemas', 123])
print(estudiante.items())   # dict_items([('nombre', 'Luis'), ('carrera', 'Sistemas'), ('id', 123)])
