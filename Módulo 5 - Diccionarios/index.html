Módulo 5 — Diccionarios

Este módulo introduce los diccionarios, la estructura de Python para almacenar datos como pares clave: valor. Se cubre cómo crearlos, acceder y modificar sus elementos de forma segura, y las tres formas de recorrerlos con un bucle for para buscar, filtrar y combinar información.

Contenido

[+] 5.1 Diccionarios   Creación, acceso con [] y .get(), añadir/modificar/eliminar, .keys()/.values()/.items() [+] 5.2 Iterar diccionarios   Iterar sobre claves, valores e items; búsqueda por clave, .get() y por valor

Shortcuts de Python útiles en este módulo

Crear y acceder

persona = {"nombre": "Ana", "edad": 30}

print(persona["nombre"])          # Ana
print(persona.get("telefono"))    # None
print(persona.get("pais", "N/A")) # N/A (valor por defecto)

Añadir, modificar y eliminar

persona["edad"] = 31         # modifica (la clave ya existe)
persona["ciudad"] = "Quito"  # añade (clave nueva)

del persona["ciudad"]
edad = persona.pop("edad")   # elimina y devuelve el valor

.keys() / .values() / .items()

d = {"a": 1, "b": 2}

d.keys()    # dict_keys(['a', 'b'])
d.values()  # dict_values([1, 2])
d.items()   # dict_items([('a', 1), ('b', 2)])

Iterar con .items()

inventario = {"manzanas": 50, "peras": 20}

for fruta, cantidad in inventario.items():
    print(f"Hay {cantidad} unidades de {fruta}")

Búsqueda por clave

contactos = {"Ana": "555-1234"}

if "Ana" in contactos:
    print(contactos["Ana"])
else:
    print("No encontrado")

Búsqueda por valor

notas = {"Ana": 9.5, "Luis": 7.0, "Eva": 9.5}

altas = []
for nombre, nota in notas.items():
    if nota == 9.5:
        altas.append(nombre)
