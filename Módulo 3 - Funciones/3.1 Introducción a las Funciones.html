Introducción a las Funciones

Unidad 03

Qué son las funciones, cómo se definen y por qué son la herramienta más importante para organizar y reutilizar código.

El Problema

Código que se Repite

Imagina que tienes que calcular el área de tres rectángulos distintos:

largo1 = 5
ancho1 = 3
area1 = largo1 * ancho1
print(f"Área 1: {area1}")

largo2 = 8
ancho2 = 4
area2 = largo2 * ancho2
print(f"Área 2: {area2}")

largo3 = 2
ancho3 = 7
area3 = largo3 * ancho3
print(f"Área 3: {area3}")

La Solución

El Principio DRY

"Don't Repeat Yourself"
No te repitas a ti mismo

Sin funciones

Si la fórmula cambia, debes corregirla en 3, 10 o 100 lugares distintos.

Con funciones

La lógica vive en un solo lugar. Corriges una vez, funciona en todas partes.

La Solución

El Mismo Problema, Resuelto

def calcular_area(largo, ancho):
    return largo * ancho

print(f"Área 1: {calcular_area(5, 3)}")
print(f"Área 2: {calcular_area(8, 4)}")
print(f"Área 3: {calcular_area(2, 7)}")

La lógica (largo * ancho) existe en un solo lugar. El código es más corto, más claro y más fácil de mantener.

La Estructura

Anatomía de una Función

def calcular_area(largo, ancho):
    """Calcula el área de un rectángulo."""
    resultado = largo * ancho
    return resultado

1. def

Palabra clave que le dice a Python: "voy a definir una función".

2. Nombre

Identificador de la función. Usa snake_case y verbos de acción.

3. Parámetros

Variables de entrada entre paréntesis. Reciben los datos que necesita la función.

La Estructura

Cuerpo y Retorno

El Cuerpo

Todo el código con 4 espacios de indentación. Es la lógica que se ejecuta cuando se llama la función.

def mi_funcion():
    # ← este espacio
    # es el cuerpo
    x = 10

El return

Entrega el resultado al código que llamó la función. Termina la ejecución de la función inmediatamente.

def doblar(n):
    return n * 2
    # nada aquí
    # se ejecuta

Definir vs. Llamar

Invocando una Función

Definir

Escribir la función. La computadora la registra en memoria pero no la ejecuta. Es como guardar una receta.

def saludar(nombre):
    print(f"Hola, {nombre}!")
# Esto no imprime nada aún

Llamar (Invocar)

Ejecutar la función escribiendo su nombre con paréntesis. Es como seguir la receta para cocinar.

saludar("Ana")
# Salida: Hola, Ana!
saludar("Luis")
# Salida: Hola, Luis!

Capturar el Resultado

Usar el Valor Retornado

def calcular_area(largo, ancho):
    return largo * ancho

# Opción 1: Guardar el resultado en una variable
area = calcular_area(5, 3)
print(area)              # 15

# Opción 2: Usar el resultado directamente
print(calcular_area(8, 4))  # 32

# Opción 3: Usar el resultado en una expresión
total = calcular_area(2, 7) + calcular_area(3, 3)
print(total)             # 23

Un Detalle Importante

Funciones Sin return

No toda función necesita devolver un valor. Cuando una función solo realiza una acción (como imprimir) y no tiene return, Python retorna automáticamente el valor especial None.

def mostrar_bienvenida(nombre):
    print(f"Bienvenido al sistema, {nombre}!")

resultado = mostrar_bienvenida("Carlos")
print(resultado)  # None

Procedimiento vs. Función

¿Cuándo usar cada uno?

Sin retorno (Procedimiento)

Cuando la función existe para producir un efecto: imprimir algo en pantalla, modificar una lista, etc.

def imprimir_factura(total):
    print(f"Total: ${total}")

Con retorno (Función)

Cuando la función existe para calcular y entregar un resultado que necesitaremos usar más adelante.

def calcular_iva(precio):
    return precio * 0.15

Trampa común: Nunca hagas x = print("algo"). print() no retorna nada útil — su trabajo es mostrar, no calcular.

Buenas Prácticas

Documentar con Docstrings

Un docstring es una cadena de texto entre """triple comillas""" ubicada justo después de la definición de la función. Describe qué hace, qué recibe y qué retorna.

def calcular_imc(peso, altura):
    """
    Calcula el Índice de Masa Corporal.
    peso: peso en kilogramos (float)
    altura: altura en metros (float)
    Retorna el IMC como número decimal.
    """
    return peso / (altura ** 2)

Puedes leer el docstring de cualquier función con help(calcular_imc). Es el mismo sistema que usa Python internamente para documentar print(), len(), etc.

Nombramiento

Convenciones para Funciones

Usa snake_case

Todo en minúsculas, palabras separadas por guion bajo. Es el estándar de Python (PEP 8).

# Correcto
def calcular_promedio():
    ...

# Incorrecto
def CalcularPromedio():
    ...

Usa verbos de acción

El nombre debe describir qué hace la función, no qué es. Prefijos comunes:

  • calcular_ → procesa y retorna un número
  • obtener_ → busca y retorna un dato
  • mostrar_ → imprime en pantalla
  • verificar_ → comprueba una condición
