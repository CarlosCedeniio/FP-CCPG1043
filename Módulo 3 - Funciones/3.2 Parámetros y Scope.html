Parámetros y Scope

Unidad 03

Cómo las funciones reciben datos, devuelven múltiples resultados y por qué cada función vive en su propio mundo aislado.

Una Distinción Clave

Parámetro vs. Argumento

Parámetro

La variable que aparece en la definición de la función. Es el molde, el nombre que usaremos internamente. No tiene valor todavía.

def saludar(nombre):
#           ↑ PARÁMETRO
    print(f"Hola, {nombre}!")

Argumento

El valor real que le pasamos al llamar la función. Es el dato concreto que llenará el molde.

saludar("Ana")
#       ↑ ARGUMENTO
# "Ana" se asigna a nombre

Múltiples Entradas

Varios Parámetros

Una función puede recibir varios parámetros separados por comas. El orden importa: el primer argumento va al primer parámetro, el segundo al segundo, y así.

def calcular_promedio(nota1, nota2, nota3):
    suma = nota1 + nota2 + nota3
    return suma / 3

resultado = calcular_promedio(8.5, 9.0, 7.5)
print(resultado)  # 8.333...

Valores Opcionales

Parámetros por Defecto

Puedes asignar un valor a un parámetro usando = en la definición. Si el usuario no pasa ese argumento, se usará el valor por defecto automáticamente.

def calcular_precio_final(precio, iva=0.15):
    return precio + (precio * iva)

# Usa el IVA por defecto (15%)
print(calcular_precio_final(100))    # 115.0

# Especifica un IVA distinto
print(calcular_precio_final(100, 0.05))  # 105.0

Regla Importante

Los Defaults van al Final

Los parámetros con valor por defecto siempre deben estar después de los parámetros sin valor por defecto. De lo contrario, Python no puede saber cuál argumento corresponde a cuál parámetro.

Correcto

def funcion(a, b, c=10):
    ...

Error de Sintaxis

def funcion(a=10, b, c):
    # SyntaxError!

Más de un Resultado

Retornar Múltiples Valores

Una función puede retornar varios valores a la vez separándolos con comas. Python los empaqueta automáticamente en una tupla.

def calcular_estadisticas(numeros):
    minimo = min(numeros)
    maximo = max(numeros)
    promedio = sum(numeros) / len(numeros)
    return minimo, maximo, promedio

notas = [7.5, 9.0, 6.0, 8.5]
resultado = calcular_estadisticas(notas)
print(resultado)  # (6.0, 9.0, 7.75)

Desempaquetar el Resultado

Tuple Unpacking

En lugar de guardar la tupla completa, puedes asignar cada valor a su propia variable en una sola línea:

def calcular_estadisticas(numeros):
    return min(numeros), max(numeros), sum(numeros)/len(numeros)

notas = [7.5, 9.0, 6.0, 8.5]

# Tuple unpacking: cada valor va a su variable
minimo, maximo, promedio = calcular_estadisticas(notas)

print(f"Mínimo:   {minimo}")    # 6.0
print(f"Máximo:   {maximo}")    # 9.0
print(f"Promedio: {promedio}")  # 7.75

El Mundo Privado de las Funciones

Scope Local

Las variables que creas dentro de una función solo existen mientras esa función se ejecuta. Al terminar, desaparecen. Este concepto se llama scope local.

def calcular_doble(numero):
    resultado = numero * 2  # "resultado" solo existe aquí
    return resultado

calcular_doble(5)
print(resultado)  # NameError: 'resultado' no existe aquí

Analogía

Lo que pasa dentro, queda dentro

Piensa en cada función como una habitación con paredes opacas. Lo que ocurre dentro no es visible desde afuera, y lo que existe afuera no entra automáticamente adentro.

Variables locales

Existen solo dentro de la función. Se crean al entrar y se destruyen al salir.

Variables globales

Existen fuera de las funciones. Las funciones pueden leerlas, pero no deben depender de ellas.

Regla de Diseño

Toda Info Entra por Parámetros

Incorrecto

La función usa una variable externa. Si esa variable cambia o no existe, la función falla.

tasa_iva = 0.15  # variable externa

def calcular_iva(precio):
    # Dependencia oculta: usa tasa_iva
    return precio * tasa_iva

Correcto

La función recibe todo lo que necesita como parámetros. Es independiente y predecible.

def calcular_iva(precio, tasa):
    # Sin dependencias externas
    return precio * tasa

calcular_iva(100, 0.15)

Resolución de Problemas

Errores Comunes

TypeError: faltan argumentos

Llamar una función sin pasar todos los argumentos requeridos.

def sumar(a, b):
    return a + b

sumar(5)
# TypeError: sumar() missing
# 1 required argument: 'b'

TypeError: demasiados argumentos

Pasar más argumentos de los que la función espera.

def saludar(nombre):
    print(f"Hola, {nombre}!")

saludar("Ana", "Luis")
# TypeError: saludar() takes 1
# argument but 2 were given
