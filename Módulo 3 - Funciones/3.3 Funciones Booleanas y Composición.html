Unidad 03

Funciones que responden preguntas con Verdadero o Falso, y cómo combinar funciones para resolver problemas más complejos.

Funciones que Responden Preguntas

¿Qué es una Función Booleana?

Es una función cuyo return siempre entrega True o False. En lugar de calcular un número, evalúa una condición.

Prefijo es_

Comprueba una característica: es_par, es_adulto.

Prefijo tiene_

Verifica si algo existe: tiene_descuento, tiene_stock.

Prefijo puede_

Comprueba un permiso o capacidad: puede_votar.

Ejemplos

Funciones Booleanas en Acción

def es_par(numero):
    """Retorna True si el número es par."""
    return numero % 2 == 0

def es_mayor_de_edad(edad):
    """Retorna True si la persona es mayor de 18."""
    return edad >= 18

def tiene_descuento(monto_compra):
    """Retorna True si la compra supera $50."""
    return monto_compra > 50

# Uso
print(es_par(4))              # True
print(es_mayor_de_edad(16))   # False
print(tiene_descuento(75.0))  # True

Error Clásico

return vs. comparar

Incorrecto

Se imprime la comparación en lugar de retornarla. La función retorna None.

def es_par(numero):
    print(numero % 2 == 0)
    # No retorna nada útil

Correcto

Se retorna el resultado de la comparación directamente como True o False.

def es_par(numero):
    return numero % 2 == 0
    # Retorna True o False

Funciones que Usan Funciones

Composición Básica

Una función puede llamar a otra función dentro de su cuerpo. Esto nos permite construir soluciones complejas a partir de piezas pequeñas y reutilizables.

def es_par(numero):
    return numero % 2 == 0

def mostrar_paridad(numero):
    if es_par(numero):          # Llama a es_par
        print(f"{numero} es par")
    else:
        print(f"{numero} es impar")

mostrar_paridad(7)  # 7 es impar
mostrar_paridad(4)  # 4 es par

Construir con Bloques

Funciones que Llaman Funciones

def calcular_iva(precio, tasa=0.15):
    return precio * tasa

def aplicar_descuento(precio, porcentaje):
    return precio * (1 - porcentaje)

def calcular_precio_final(precio_base):
    """Aplica descuento del 10% y luego el IVA."""
    precio_con_descuento = aplicar_descuento(precio_base, 0.10)
    precio_final = precio_con_descuento + calcular_iva(precio_con_descuento)
    return precio_final

print(calcular_precio_final(100))  # 103.5

Cada función hace una sola cosa bien. calcular_precio_final no necesita saber cómo se calcula el IVA; simplemente lo pide.

Reto Mental

¿Qué imprimirá este código?

def es_aprobado(nota):
    return nota >= 7.0

def mostrar_resultado(nombre, nota):
    if es_aprobado(nota):
        print(f"{nombre}: Aprobado ({nota})")
    else:
        print(f"{nombre}: Reprobado ({nota})")

mostrar_resultado("Ana", 8.5)
mostrar_resultado("Luis", 5.0)

Razona el flujo antes de ejecutar.

Resolución de Problemas

Errores Comunes

NameError por Scope

Intentar usar desde afuera una variable que solo existe dentro de una función.

def calcular():
    total = 100

calcular()
print(total)
# NameError: 'total' no definida

None Inadvertido

Olvidar el return en una función que debería retornar un valor.

def calcular_doble(n):
    resultado = n * 2
    # Olvidé: return resultado

x = calcular_doble(5)
print(x)  # None, no 10
