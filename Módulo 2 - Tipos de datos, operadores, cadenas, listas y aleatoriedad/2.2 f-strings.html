Presentación profesional de datos: Inserción de variables en textos, redondeo dinámico y el estándar f-string en Python 3.

La necesidad de "inyectar" datos

El problema de la concatenación

Usar el símbolo + para unir textos y variables es tedioso y propenso a errores (requiere convertir todo a str).

La solución: Formateo

Permite crear "plantillas" de texto donde Python rellena los espacios con valores reales de forma automática.

Evolución del Formateo

  • 1. f-strings (Python 3.6+)

    El estándar actual. Rápido, legible y elegante.

  • 2. .format() (Python 2.7 / 3.0)

    Versátil, pero requiere más código. Útil para plantillas externas.

f-strings: El estándar moderno

Se identifican por la letra f antes de las comillas.


nombre = "Carlos"
materia = "Fundamentos de Programación"

# Las variables van directamente entre llaves {}
mensaje = f"Hola {nombre}, bienvenido a {materia}"
print(mensaje)

Poder oculto: Redondeo

Controla cuántos decimales mostrar sin modificar el valor real.


pi = 3.14159265
# :.2f significa "redondear a 2 decimales flotantes"
print(f"El valor aproximado de PI es {pi:.2f}")

precio = 125.4
print(f"Total a pagar: ${precio:.2f}") 
# Salida: Total a pagar: $125.40

str.format(): La alternativa

Utiliza marcadores de posición {} que se llenan al final.


carrera = "Ingeniería"
facultad = "FIMCP"

texto = "Estudio {} en la {}".format(carrera, facultad)
print(texto)

¿Por qué usar .format()?

1. Es compatible con versiones antiguas de Python.

2. Permite reutilizar la misma variable en varios lugares fácilmente.


# Usando índices
msg = "{0} es de la ESPOL. ¡Vamos {0}!".format("Ana")
print(msg)

Errores Comunes

Olvidar la 'f'

Si escribes "{var}" en lugar de f"{var}", Python imprimirá las llaves literalmente.

Tipos incompatibles

El redondeo :.2f solo funciona con números. Aplicarlo a un texto causará un ValueError.
