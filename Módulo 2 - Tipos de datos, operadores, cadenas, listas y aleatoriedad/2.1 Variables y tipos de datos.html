Variables y Tipos de Datos

Unidad 02 • Clase 01

Conceptos fundamentales, convenciones y conversiones.

Tipos de Datos Primitivos

int (Entero)

Representa números sin parte decimal, positivos o negativos.

float (Punto Flotante)

Representa números con precisión decimal.

str (Cadena de texto)

Secuencia de caracteres encerrados en comillas.

bool (Booleano)

Representa valores de lógica binaria: True o False.

Ejemplos de Datos

# Definición de distintos tipos
entero = 10              # int
decimal = 10.5           # float
nombre = "ESPOL"         # str
es_estudiante = True     # bool

# Comportamiento de operadores
print(5 + 5)             # 10 (Suma)
print("5" + "5")         # "55" (Concatenación)

Definición de Variables

En Python, una variable es una referencia (etiqueta) a un objeto almacenado en la memoria.

A diferencia de otros lenguajes, no se reserva un espacio fijo para el nombre, sino que el nombre "apunta" al valor actual.

x = 100    # x apunta al objeto 100
y = x      # y ahora apunta al mismo objeto 100
x = "Hola" # x ahora apunta a un objeto de texto

Convenciones de Nombramiento

snake_case

Uso de guiones bajos para separar palabras. Es el estándar recomendado en Python (PEP 8).

nombre_usuario = "Carlos"

camelCase

La primera letra en minúscula y las siguientes palabras inician con mayúscula.

nombreUsuario = "Carlos"

Entrada de Datos: input()

La función input() detiene la ejecución del programa para esperar una respuesta del usuario.

Regla técnica: Todo valor capturado mediante input() es estrictamente de tipo str.

valor = input("Ingrese un número: ")
print(type(valor)) # Resultado: <class 'str'>

Conversión de Tipos (Casting)

Es el proceso de transformar un objeto de un tipo a otro compatible.

  • int(x): Convierte a entero.
  • float(x): Convierte a punto flotante.
  • str(x): Convierte a cadena de texto.
  • bool(x): Convierte a booleano.

Ejemplos de Conversión

# A Entero (int)
print(int("25"))      # 25
print(int(3.99))      # 3 (Trunca los decimales)

# A Flotante (float)
print(float("3.14"))  # 3.14
print(float(10))      # 10.0

# A Cadena de Texto (str)
print(str(150))       # "150"

# A Booleano (bool)
print(bool(1))        # True
print(bool(0))        # False
print(bool(""))       # False (String vacío)
print(bool("ESPOL"))  # True (String con contenido)

Aplicación Práctica

# Captura de datos numéricos
edad_texto = input("Dime tu edad: ")
edad_numero = int(edad_texto) # Conversión necesaria

# Ahora es posible realizar operaciones aritméticas
proximo_anio = edad_numero + 1
print(f"En un año tendrás: {proximo_anio}")

Errores de Conversión (ValueError)

Si el contenido del texto no representa un número válido, el intérprete lanzará un error.

# Esto causará que el programa falle
numero = int("Veinte") 
# ValueError: invalid literal for int()
