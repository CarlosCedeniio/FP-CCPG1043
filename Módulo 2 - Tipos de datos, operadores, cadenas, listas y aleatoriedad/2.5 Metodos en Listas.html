Métodos en Listas

Unidad 02

Manipulación avanzada de colecciones: métodos de inserción, eliminación, ordenamiento y búsqueda de datos.

Conceptos

Definición y Estructura

Mutable

A diferencia de los strings, las listas pueden cambiar sus elementos sin necesidad de crear una copia nueva.

Colección

Permite almacenar cualquier tipo de dato (números, textos, booleanos) de forma organizada.

Modificación

Añadir Elementos

Existen dos formas principales de hacer crecer una lista:

.append(valor)

Agrega el elemento al final de la lista. Es el método más común.

.insert(i, valor)

Inserta un elemento en la posición específica desplazando el resto.

Ejemplo de Adición


invitados = ["Ana", "Luis"]

# Al final de la cola
invitados.append("Marta") 
# ["Ana", "Luis", "Marta"]

# Colarse en el primer puesto (índice 0)
invitados.insert(0, "Carlos")
# ["Carlos", "Ana", "Luis", "Marta"]

Modificación

Eliminar Elementos

.remove(x)

Busca el valor x y lo borra. Falla si no existe.

.pop()

Elimina y retorna el último elemento de la lista.

.pop(i)

Elimina el elemento en la posición i.

Diferencia de enfoque


frutas = ["Manzana", "Pera", "Uva", "Pera"]

# Por valor (borra la primera que encuentra)
frutas.remove("Pera") 
# ["Manzana", "Uva", "Pera"]

# Por posición (el segundo elemento)
eliminado = frutas.pop(1)
print(eliminado) # Salida: Uva

Gestión

Orden y Utilidad

Método / Función Acción
len(lista) Retorna cuántos elementos hay.
lista.sort() Ordena la lista original (in-place).
sorted(lista) Crea una copia ordenada sin tocar la original.
lista.reverse() Invierte el orden de los elementos.

Búsqueda e Información


notas = [10, 7, 9, 8]

print(len(notas))    # Salida: 4
print(notas.index(9)) # Salida: 2 (¿dónde está el 9?)

# Ordenamiento
notas.sort() 
print(notas) # Salida: [7, 8, 9, 10]

Cierre de Sesión

Errores Fatales

ValueError

Ocurre cuando intentas usar .remove() con un valor que no está en la lista.

pop de lista vacía

Intentar sacar un elemento de una lista que no tiene nada dará error.
