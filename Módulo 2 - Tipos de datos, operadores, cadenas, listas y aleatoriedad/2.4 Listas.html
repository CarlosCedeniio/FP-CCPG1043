Unidad 02

Introducción a las colecciones de datos: definición, acceso posicional y la capacidad de modificar elementos en Python.

Conceptos Fundamentales

¿Qué es una Lista?

Definición

Es una colección ordenada y mutable de objetos. Permite agrupar múltiples valores bajo un solo nombre de variable.

Analogía

Imagina un organizador de píldoras o una lista de compras: cada espacio tiene una posición y puedes cambiar lo que hay dentro.

Creación de Listas

En Python, usamos corchetes [] para definir una lista y comas para separar los elementos.


# Lista de strings (carreras ESPOL)
carreras = ["Computación", "Artes", "Mecánica"]

# Lista de números (calificaciones)
notas = [9.5, 8.0, 10.0, 7.5]

# Lista vacía
mi_lista = []

El Sistema de Índices

Imagina la lista como un edificio de un solo piso con varios cuartos:

"Python"

Índice 0

Inicio

"Java"

Índice 1

+1 Salto

"C++"

Índice 2

+2 Saltos

El índice indica cuántos saltos damos desde el principio para llegar al valor.

Diferencia de Perspectiva

Humano vs. Python

Mentalidad Humana

"Este es el primer elemento de mi lista de compras".

Posición: 1

Mentalidad Python

"Este elemento está a cero saltos de distancia del inicio".

Índice: 0

💡 Regla de Oro: El índice máximo siempre es Largo - 1.

Acceso Inverso

Índices Negativos

Python permite contar desde el final hacia atrás. Esto es muy útil cuando no sabemos qué tan larga es la lista.

Elemento "Python" "Java" "C++" (Último)
Índice Normal 0 1 2
Índice Negativo -3 -2 -1

Tip: lista[-1] siempre te dará el último elemento, sin importar el tamaño.

Código en Acción


estudiantes = ["Ana", "Luis", "Marta"]

# Acceder al primer elemento
print(estudiantes[0])  # Salida: Ana

# Modificar al segundo estudiante
estudiantes[1] = "Carlos"
print(estudiantes)     # Salida: ["Ana", "Carlos", "Marta"]
