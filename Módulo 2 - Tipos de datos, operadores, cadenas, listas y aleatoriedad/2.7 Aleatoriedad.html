Ampliando Python

¿Qué es una Librería?

Definición

Es un conjunto de herramientas (código) ya escritas por expertos que podemos "pedir prestadas" para no tener que inventar todo desde cero.

Analogía

Python es como un teléfono nuevo. Las librerías son las "Apps" que instalas para darle funciones extra (GPS, Cámara, Juegos).

Se activan con la palabra clave import nombre_libreria

Anatomía del Código

Métodos y Argumentos

Para usar una herramienta, debemos entender sus partes:

lista.index("Dato")

1. El Método

Es la acción que realiza el objeto. (Ej: .index, .choice, .upper).

2. El Argumento

Son los ingredientes o la información extra que el método necesita para funcionar.

Importar Herramientas

El Módulo random

Python tiene herramientas incorporadas, pero algunas vienen guardadas en cajas especiales llamadas módulos para ahorrar memoria. Para usar el azar, primero debemos abrir esa caja usando la palabra clave import.

import random

Lanzando los Dados

Números Enteros: randint

¿Qué hace?

Genera un número entero aleatorio entre un valor inicial y uno final.

Ej: Simular un dado de 6 caras.

⚠️ Regla Especial

A diferencia de otras funciones en Python, randint(a, b) SÍ incluye el último número (b).

Probabilidades y Porcentajes

El Método .random()

¿Qué hace?

Genera un número decimal (float) estrictamente entre 0.0 y 1.0 (sin incluir el 1.0).

Casos de uso

Es ideal para simular probabilidades. Piensa en ello como un porcentaje al azar entre 0% y 99.9%.


import random

# Generar una probabilidad de lluvia
probabilidad = random.random()
print(probabilidad) # Salida de ejemplo: 0.73419283

Decimales en un Rango

El Método .uniform()

Si randint te da un entero exacto entre dos números, uniform(a, b) te da cualquier valor decimal posible entre esos dos límites.

La Analogía

Medir algo en el mundo real. Si mides la temperatura, rara vez es exactamente 25 grados; puede ser 25.43 grados.

Argumentos requeridos:

(límite_inferior, límite_superior)

# Generar el peso aleatorio de una manzana entre 100g y 150g
peso = random.uniform(100.0, 150.0)

# Redondear para que no se vea feo en pantalla
peso_final = round(peso, 2)
print(peso_final) # Salida de ejemplo: 134.57

Extraer Elementos

La Familia "Choice"

Cuando ya tienes una lista y quieres elegir elementos al azar de ella, Python te ofrece tres estrategias diferentes:

Método Cantidad ¿Se pueden repetir? (Reemplazo)
.choice() 1 solo elemento No aplica
.choices() Varios (k) SÍ. (Devuelve el papel a la bolsa)
.sample() Varios (k) NO. (Se queda con el papel)

Modificando la Lista

Desordenar: shuffle

El método random.shuffle(lista) funciona exactamente como barajar un mazo de cartas.

[ 1, 2, 3, 4 ]   ➡️   🔄 SHUFFLE 🔄   ➡️   [ 3, 1, 4, 2 ]

Cuidado: Modifica la lista original "in-place" (en su mismo lugar). Nunca hagas x = random.shuffle(lista), porque destruirás tu variable.

Código en Acción

import random

estudiantes = ["Ana", "Luis", "Marta", "Carlos", "Eva"]

# 1. Un solo ganador
ganador = random.choice(estudiantes)

# 2. Dos voluntarios (no puede ser la misma persona 2 veces)
voluntarios = random.sample(estudiantes, k=2)

# 3. Lanzar una moneda 3 veces (puede salir "Cara" varias veces)
moneda = ["Cara", "Sello"]
lanzamientos = random.choices(moneda, k=3)

# 4. Barajar el orden de exposición
random.shuffle(estudiantes)
print(estudiantes)

Resolución de Problemas

Errores Comunes

NameError

"name 'random' is not defined". Ocurre si olvidas escribir import random al inicio de tu archivo.

ValueError en Sample

Tratar de sacar más elementos de los que hay. Ej: Usar sample(lista, k=5) en una lista que solo tiene 3 elementos.
