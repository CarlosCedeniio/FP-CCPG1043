Acceso: Indexación

Cada carácter tiene una dirección única dentro del string.

materia = "Python"
# P(0) y(1) t(2) h(3) o(4) n(5) 
print(materia[0])   # Resultado: 'P'
print(materia[-1])  # Resultado: 'n'

Slicing (Rebanado)

Sintaxis: string[inicio:fin]

ciudad = "Guayaquil"
print(ciudad[0:5]) # 'Guaya'
print(ciudad[:5])  # 'Guaya' (equivale a 0:5)
print(ciudad[5:])  # 'quil'  (hasta el final)

Transformación de Texto

Limpieza

.strip() elimina espacios en los bordes.

Caja

.upper(), .lower(), .title()

Ejemplo de Aplicación

correo = "   ESTUDIANTE@ESPOL.EDU.EC   "
# Encadenamiento de métodos
limpio = correo.strip().lower()
print(f"'{limpio}'") # 'estudiante@espol.edu.ec'

Salida Dinámica: f-strings

La forma más legible de inyectar variables en un texto.

nombre = "Carlos"
carrera = "Artes"
# F antes de las comillas
print(f"Bienvenido {nombre} de la carrera de {carrera}")
