Manipulación de Texto

Unidad 02 • Clase 02: Métodos de Strings

Dominio de herramientas para transformar, validar y limpiar datos textuales. Desde la limpieza de espacios hasta la división de estructuras complejas.

1. Transformación de Caja

Útiles para normalizar datos ingresados por usuarios.

Mayúsculas / Minúsculas

txt = "EsPoL"
print(txt.upper()) # ESPOL
print(txt.lower()) # espol

Formato Título

nom = "juan perez"
print(nom.title())     # Juan Perez
print(nom.capitalize())# Juan perez

Swapcase y Casefold

swapcase() invierte mayúsculas y minúsculas.

alerta = "Atención Estudiantes"
print(alerta.swapcase()) # aTENCIÓN eSTUDIANTES

2. Búsqueda y Conteo

¿Cómo encontrar patrones dentro de una cadena?

frase = "Programar en Python es genial, amo Python"
# Cuenta ocurrencias
print(frase.count("Python")) # 2

# Encuentra la posición (índice)
print(frase.find("genial"))  # 23
print(frase.find("Java"))    # -1 (no existe)

Validación de Extremos

Muy usado para filtrar archivos o dominios de correo.

correo = "cedeno@espol.edu.ec"
print(correo.endswith("@espol.edu.ec")) # True

archivo = "notas.pdf"
print(archivo.startswith("notas")) # True

3. Limpieza y Reemplazo

Fundamental para procesar datos "sucios" o de formularios.

usuario = "   carlos_99   \n"
# Elimina espacios, tabs y saltos de línea
limpio = usuario.strip()
print(f"'{limpio}'") # 'carlos_99'

Método .replace()

Sustituye todas las ocurrencias de un sub-string.

fecha = "22/10/2023"
nueva_fecha = fecha.replace("/", "-")
print(nueva_fecha) # 22-10-2023

4. Validación de Tipos

¿Qué contiene realmente el string?

Método Verifica si...
.isdigit()Solo contiene números (0-9)
.isalpha()Solo contiene letras
.isalnum()Letras y números (no símbolos)
.isspace()Solo espacios en blanco

Ejemplo de Validación

cedula = "0912345678"
if cedula.isdigit():
    print("Cédula válida (solo números)")
else:
    print("Error: La cédula contiene caracteres extraños")

5. Split y Join

Convertir strings en listas y viceversa.

Split (Dividir)

data = "Artes,Ingenieria,Humanidades"
carreras = data.split(",") 
# Resultado: ['Artes', 'Ingenieria', 'Humanidades']

Join (Unir)

El string que llama al método es el "pegamento".

lista = ["Python", "es", "facil"]
frase = " ".join(lista)
print(frase) # "Python es facil"
