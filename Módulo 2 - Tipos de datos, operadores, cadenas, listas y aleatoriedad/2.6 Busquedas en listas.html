Búsqueda en Listas

Unidad 02

Estrategias para encontrar datos dentro de colecciones: uso de operadores de pertenencia, métodos de localización y manejo de elementos duplicados.

Preguntas de Sí o No

El Operador in

A menudo solo necesitamos saber si un elemento existe en nuestra lista, sin importar dónde esté. El operador in (en) funciona exactamente como el lenguaje humano.

¿Qué devuelve?

Siempre retorna un valor Booleano: True si lo encuentra, o False si no está en la lista.

Sensible a Mayúsculas

Recuerda que para Python, "espol" y "ESPOL" son elementos totalmente distintos.

Obteniendo la Posición

El Método .index()

Si además de saber que existe, necesitas saber en qué casillero (índice) se encuentra, usamos el método .index(valor).

Ejemplo: lista_compras.index("Leche") te dirá a cuántos saltos está el elemento.

Atención Estudiantes

El Problema de los Duplicados

¿Qué pasa si tienes varios elementos idénticos en la misma lista y usas .index()?

10

Índice 0

"Ana"

Índice 1

¡Lo encuentra y se detiene!

9.5

Índice 2

"Ana"

Índice 3

Ignorado

El método .index() solo te devolverá la primera coincidencia que encuentre leyendo de izquierda a derecha.

Código en Acción


materias = ["Arte", "Cálculo", "Física", "Cálculo"]

# 1. Verificar si existe (Devuelve True/False)
print("Física" in materias)    # Salida: True
print("Química" in materias)   # Salida: False

# 2. Encontrar la posición del primer "Cálculo"
posicion = materias.index("Cálculo")
print(posicion)                # Salida: 1

notas = [8, 10, 9, 10, 7]

Prevención de Errores

La Estrategia Segura

El Peligro: ValueError

Si usas .index("X") y la "X" no está en la lista, tu programa se detendrá con un error y colapsará.

La Solución

Combina ambos: Primero usa in para preguntar si existe. Solo si te da True, usas .index() para buscarlo.
